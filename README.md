# Task Board (Full-Stack)

Мой первый полноценный Full-Stack проект — интерактивная доска для управления задачами (Kanban).

## 🛠️ Стек технологий:
* **Frontend:** HTML5, CSS3, Vanilla JavaScript (Drag & Drop, Modals)
* **Backend:** Python, Flask
* **Database:** SQLite
* **Безопасность:** Хэширование паролей (Werkzeug), сессии, защита от SQL-инъекций.

## ✨ Функционал:
* Регистрация и авторизация пользователей.
* Создание, удаление и редактирование задач.
* Перетаскивание задач между колонками (с сохранением в базу данных).
* У каждого пользователя свой личный список задач.

## 🚀 Как запустить локально:
1. Клонируйте репозиторий.
2. Установите зависимости: `pip install -r requirements.txt` (или `pip install flask flask-cors python-dotenv werkzeug`).
3. Создайте файл `.env` и добавьте туда `SECRET_KEY='ваш_секретный_ключ'`.
4. Запустите сервер: `python server.py`.
